# 💰 Sistema de Controle de Gastos

Uma aplicação web moderna e intuitiva para gerenciar suas despesas semanais com uma interface belíssima e funcional.

![License](https://img.shields.io/badge/license-ISC-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ Características

- 🎨 **Design Moderno**: Interface com gradientes vibrantes e efeitos glassmorphism
- 📊 **Organização por Semana**: Gastos agrupados automaticamente por semana
- 💾 **Armazenamento Local**: Dados salvos no navegador (LocalStorage)
- ✅ **Marcar como Pago**: Sistema de checkbox para controlar pagamentos
- 🗑️ **Exclusão Fácil**: Remova gastos com um clique
- 📱 **Responsivo**: Funciona perfeitamente em desktop e mobile
- 🎭 **Animações Suaves**: Transições e efeitos visuais agradáveis
- 💵 **Total Semanal**: Cálculo automático do total de gastos por semana

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/marcosmartins2/Projeto-Controle-de-Gastos.git
   cd Projeto-Controle-de-Gastos
   ```

2. **Instale as dependências** (opcional, apenas para desenvolvimento)
   ```bash
   npm install
   ```

3. **Abra o arquivo**
   - Simplesmente abra o arquivo `index.html` no seu navegador
   - Ou use: `npm start`

## 🎯 Como Funciona

1. Digite o nome do gasto no campo principal
2. Pressione Enter ou clique no botão (+)
3. Digite a data do pagamento
4. Pressione Enter ou clique no botão (+)
5. Digite o valor do gasto
6. Pressione Enter ou clique no botão (+)
7. Pronto! Seu gasto foi registrado e organizado por semana

### Recursos Adicionais:
- ✅ Marque o checkbox para indicar que o gasto foi pago
- 🗑️ Clique no ícone da lixeira para excluir um gasto
- 📊 Veja o total de gastos por semana automaticamente

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da aplicação

- **JavaScript**: Lógica e interatividade
- **Tailwind CSS**: Framework CSS (via CDN)
- **Font Awesome**: Ícones modernos
